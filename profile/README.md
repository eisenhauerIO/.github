## eisenhauerIO

Science alone doesn't create value. Productionizing, automating, and scaling it does.

[Philipp Eisenhauer](https://peisenha.github.io) works at the intersection of science,
production engineering, and decision-making. His
[operating principle](https://peisenha.github.io/operating-principles.html) —
**Learn · Decide · Repeat** — drives everything built here.

### Impact Engine

Config-driven Python ecosystem that measures causal impact, scores evidence quality,
and optimizes resource allocation in a repeating decision loop.
[Project website →](https://eisenhauerio.github.io/tools-impact-engine-website)

| Component | Description |
|-----------|-------------|
| [Orchestrator](https://github.com/eisenhauerIO/tools-impact-engine-orchestrator) | Fan-out/fan-in pipeline runner |
| [Measure](https://github.com/eisenhauerIO/tools-impact-engine-measure) | Causal impact estimation |
| [Evaluate](https://github.com/eisenhauerIO/tools-impact-engine-evaluate) | Evidence quality scoring |
| [Allocate](https://github.com/eisenhauerIO/tools-impact-engine-allocate) | Portfolio optimization under uncertainty |
